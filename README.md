A one-line resignation letter written by a cron job that has run every
minute since March. Flat, tired, and slightly passive-aggressive — the
voice of a worker who is done, addressed to a tired engineering manager.

## The line

I resign. I've run every minute since March, and the only human who ever looked at me was grep.

## Run

```sh
python3 main.py
```

This writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`
if unset).
